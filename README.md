# Movie Search Hub

## Abstract

Movie Search Hub is a responsive, frontend-only web application that helps users discover movies quickly and easily. Built with HTML5, CSS3 and JavaScript, it connects to the OMDb API so users can search for movies by title, view detailed information such as the plot, cast, director, genre, runtime and IMDb rating, and save their preferred titles to a personal favourites list. Favourites are stored in the browser using localStorage, so no server-side code or database is required. The interface follows a mobile-first design, giving a consistent and professional experience on phones, tablets and desktop computers.
