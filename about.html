ABOUT THE PROJECT

Movie Search Hub

A simple, modern and responsive frontend movie discovery application.

🎯

Purpose

Movie Search Hub allows users to search for movies, view detailed information and create a personal favourites collection without a database.

💻

Technology

The application uses HTML5 for structure, CSS3 for the interface and JavaScript for search, API communication, navigation and local storage.

📱

Responsive

The layout adapts to desktops, tablets and mobile devices using responsive CSS and a mobile navigation menu.

💾

No Database

Favourite movies are saved in the browser using localStorage. No PHP, MySQL or server-side application is required.

API SETUP

Connect a movie API

For live movie data, add your OMDb API key inside js/app.js. The project also includes a small built-in demo catalogue so the interface remains usable before an API key is added.

const API_KEY = "YOUR_OMDB_API_KEY";
